# Data structures in C

Data structures and classic algorithms implemented from scratch in C, with one in Python.

| Area | Files |
| --- | --- |
| Linked lists | singly, doubly and circular lists: insertion, deletion, reversal, merge point, `LINKED_list.c`, `doublelinked.c`, `circularLL.c`, `DoubleCircularLL.c` |
| Stacks and queues | stack (array, linked list), queue (array, linked list, two stacks), circular queue, deque |
| Trees | binary tree, BST to doubly linked list, mirror, right view (recursive and queue-based), AVL tree, red-black tree |
| Searching and sorting | linear, interpolation and binary search (peak element), bubble (iterative and recursive), selection, merge and bucket sort |
| Graphs | Dijkstra (naive in C, heap-based in Python) |
| Recursion | linear recursion, max element, matrix multiplication, longest subsequence |
| Fun | a toy blockchain built on a linked list (`BlockchainWithDSA.c`, `bloackchainUSINGLL.c`) |

Compile any file with `gcc file.c -o out && ./out`.
